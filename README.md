# Rust-autoclicker
Autoclicker written in rust with "macro" functionality, super fast and super simple



## Build

```bash
git clone https://github.com/WinWeirdo/rust-autoclicker
cd rust-autoclicker
cargo build
```

Build the project yourself using Cargo.


## Warning
This program is not 100% working and will not work on linux or macos it wasn't designed to be cross-platform, maybe in the future I will update it.
